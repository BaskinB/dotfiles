# Welcome to my Dotfiles 🦥

Hello there! 👋

Welcome to my personal Windows Dotfiles repository. This is where I keep all my dotfiles and configuration settings to make my computing environment feel just like home. Feel free to explore and get cozy!

## Literate Configs 📚

Some of these configurations are written as Literate Configs in their respective README.md using a custom Python script. This script tangles markdown code blocks into their required formats and files, making it easier to manage and understand the configurations. By keeping the documentation and code together, it ensures that everything stays up-to-date and well-documented.

## Software

Here's a list of software that I use and configure with my dotfiles:

- **Fastfetch**: A fast and highly customizable system information tool.
- **komorebi**: A tiling window manager for Windows.
- **NeoVim**: A hyperextensible Vim-based text editor.
- **tacky-borders**: A tool to customize window borders.
- **WezTerm**: A GPU-accelerated terminal emulator.
- **YASB**: Yet Another Status Bar for displaying system information.
- **yazi**: A terminal file manager with a focus on performance and usability.
- **VSCode**: A extremely customizable code editor!

Each of these tools is configured to enhance productivity and provide a seamless experience across my computing environment.

## What's Inside? 📦

- **Dotfiles**: My personalized configuration files for various applications.

## Getting Started 🚀

To get started with my Windows Dotfiles, follow these steps:

1. **Install chezmoi**:
```sh
scoop install chezmoi
```

2. **Clone this repository**:
```sh
chezmoi init --apply https://github.com/BaskinB/dotfiles.git
```

3. **Enjoy your new setup**! 🎉
